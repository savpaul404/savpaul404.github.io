Trewda website - static HTML files

Open index.html directly in a browser, or host the folder anywhere (GitHub Pages, Netlify, any web host).
All pages sit next to index.html (about.html, faq.html, privacy.html, ...). Styles and pictures are in /assets.

GitHub Pages: upload everything in this folder (including the hidden .nojekyll file) to a repository,
then Settings > Pages > Deploy from a branch > main, folder / (root). Sub-folder addresses work too.

Forms open an email draft to support@trewda.com; nothing is sent or stored by the site.
Search tags and the sitemap point to https://trewda-home-loan-guide.lovable.app; update them if you move to a new domain.
